## 📊 Featured Portfolio Projects

###  1. English Premier League Match Outcome Prediction | Machine Learning

**Python | Scikit-learn | Feature Engineering | PCA | SMOTE | SHAP**

Developed and evaluated machine learning models to predict English Premier League match outcomes using approximately **45,952 historical football records**.

- Conducted exploratory analysis, preprocessing and feature selection.
- Applied feature engineering, categorical encoding and dimensionality reduction using PCA.
- Investigated class imbalance using SMOTE.
- Trained and compared Logistic Regression, Random Forest, Support Vector Machine, Gradient Boosting and Voting Ensemble models.
- Evaluated performance using accuracy, precision, recall, F1-score and cross-validation.
- Used SHAP to interpret model predictions and feature contributions.
- Achieved approximately **67% classification accuracy** with the selected Gradient Boosting model.
